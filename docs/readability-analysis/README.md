# readability-analysis

확장·직접 실행·자동 관찰·Windows 알림의 책임 분리 근거와 검증 결과를 보존한다.

- [application.md](application.md) — 확장 조립·UI·알림과 직접 실행 세션 수명의 책임 경계를 설명한다.
- [execution.md](execution.md) — Codex 연결·이력 대조와 Claude 실행·권한 대기의 분리 근거를 기록한다.
- [runtime.md](runtime.md) — 자동 관찰·이벤트 라우팅·Provider 계약의 가독성 정리와 유지 근거를 기록한다.
- [windows.md](windows.md) — 창 알림·helper 실행·클릭 채널의 서로 다른 자원 수명과 분리 근거를 기록한다.
